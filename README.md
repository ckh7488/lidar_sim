# LiDAR 노이즈 시뮬레이터

**장소와 날씨를 바꾸며, 실측 점군과 생성한 라이다 관측을 3D로 검토하는 도구입니다.**

먼지 · 비 · 눈 · 안개 · 햇빛과 거리 오차를 조절할 수 있습니다. 공사장, 중공업 야드, 아파트 단지, 지하 주차장 등 **8종 장소 × 3예시**와 이미 열람한 **실측 36예시**를 포함합니다.

> 현재는 **검토용 시뮬레이터**입니다. 센서별 현장 교정이나 학습 데이터 승인이 완료된 제품은 아닙니다. 화면의 주황 점이 언제나 제거 정답을 뜻하지는 않습니다.

## 바로 실행

Python **3.10 이상**과 WebGL을 지원하는 최신 Chrome 또는 Edge가 필요합니다. 실행에 인터넷 연결, 계정, 추가 Python 패키지 설치가 필요하지 않습니다.

저장소를 내려받은 폴더에서:

```sh
python tools/serve.py
```

**[시뮬레이터 열기](http://127.0.0.1:8768/)** → 종류와 장소 선택 → **새 시드로 생성**.

Windows에서 `python`을 찾지 못하면 `py -3 tools/serve.py`를 사용하세요. 이미 다른 시뮬레이터가 실행 중이면 `python tools/serve.py --port 18768`을 실행하고 [18768 포트](http://127.0.0.1:18768/)를 여세요. 종료는 실행 창에서 **Ctrl+C**입니다. HTML 파일을 더블클릭하는 대신 위 방식으로 여세요.

## 화면 읽는 법

**3D 시뮬레이션**은 조작 화면입니다. 입자 운동과 지면 설정은 펼쳐서 조절할 수 있습니다. 마우스 드래그로 회전하고 휠로 확대합니다.

**확정 내용·생성 한계**에는 합의한 설정과 아직 구현·검증하지 못한 내용이 있습니다. **생성 원리·특징**에서는 계산 가정을, **소스 목록**에서는 자료의 출처와 라벨 상태를 확인합니다.

| 보기 | 의미 |
| --- | --- |
| 공간 속 입자 | 바람·낙하 운동을 보여주는 표본. 센서 관측점과 다릅니다. |
| 라이다 관측점 | 빔, 가림, 감쇠, 검출 가정을 통과한 반환점입니다. |
| 실측 비교 | 먼지·눈·비는 다른 장소의 참고 실측입니다. 동일 장면의 정답 쌍이 아닙니다. |
| 효과 전후 | 거리 오차·안개·햇빛·경계 혼합은 같은 합성 장소를 비교합니다. |

## 무엇이 매번 바뀌나요?

**같은 장소·시드·시간·설정이면 같은 결과를 재현**합니다. 시점을 돌리거나 탭을 옮기는 동작은 난수를 바꾸지 않습니다.

- 새 시드: 지면 굴곡, 설치 기울기, 축 흔들림과 입자·반환 위치가 달라집니다.
- 비·눈·안개 강도: 기본은 노브값 고정입니다. **강도도 조금씩 변화**를 켜면 시드별로 표준편차 5%의 변동을 줍니다.
- 건물·차량·전봇대 배치: 장소의 예시 1~3을 고르면 바뀝니다. 날씨 시드가 물체 배치를 바꾸지는 않습니다.
- 안개: 반환 위치는 시드별로 바뀌지만, 유체가 흐르는 시간 애니메이션은 없습니다.

거리 오차 기본값은 **표준편차 0.06m**입니다. 지면 굴곡은 **높이 표준편차 0~0.5cm**, 앞뒤·좌우 기울기는 각각 **±0.6°**, 축 흔들림 진폭은 **0~0.7°**입니다. 모두 사용자와 정한 검토 범위이며 장비의 실측 허용오차가 아닙니다.

## AI 에이전트에게 맡기기

에이전트에게 이 저장소를 열고 **[AGENTS.md](AGENTS.md)를 먼저 읽으라**고 알려주세요. 실행·수정 위치, 보호할 조건, 검증 명령과 데이터 계약이 정리되어 있습니다.

화면 없이 한 프레임을 계산하려면 Node.js **20 이상**도 필요합니다:

```sh
python tools/build.py
node tools/simulate.cjs --config examples/dust.json --out outputs/dust.json
```

결과에는 좌표, 검토 라벨, 빔 번호, 적용한 설정과 시드가 함께 저장됩니다. 이미 있는 출력 파일은 덮어쓰지 않습니다. 자세한 사용법은 [에이전트 실행 안내](docs/agent-guide.md)에 있습니다.

## 보관 범위

v18 시뮬레이터의 활성 소스, 장면 데이터, 실측 변환 예시, 라이브러리와 출처를 포함합니다. 별도 PC 경로 없이 실행되며, 빌드 결과는 `dist/`에 만들어집니다.

원본 PCAP, 대용량 학습 데이터, 모델 가중치, 보류한 테스트 캡처와 다른 에이전트의 진행 중인 PCD·궤적 프로젝트는 포함하지 않습니다. 사내 크레인 형상과 서로 다른 이용 조건의 실측 자료가 있으므로 **저장소 전체에 공개 재배포 허가가 부여된 것은 아닙니다.** [자료·라이선스 안내](docs/data-and-rights.md)를 확인하세요.
