# LiDAR 노이즈 시뮬레이터

**장소와 날씨를 바꾸며, 실측 점군과 생성한 라이다 관측을 3D로 검토하는 도구입니다.**

먼지 · 비 · 눈 · 안개 · 햇빛과 거리 오차를 조절할 수 있습니다. 공사장, 중공업 야드, 아파트 단지, 지하 주차장 등 **8종 장소 × 3기본 배치 + 시드별 랜덤 소품·시작점**과 이미 열람한 **실측 36예시**를 포함합니다.

> 현재는 **검토용 시뮬레이터**입니다. 센서별 현장 교정이나 학습 데이터 승인이 완료된 제품은 아닙니다. 화면의 주황 점이 언제나 제거 정답을 뜻하지는 않습니다.

## 환경 전체를 보고 직접 생성하기

**새 검토실은 24개 환경의 실제 형상, 8종 생성기 설명, 생성·경로·재생을 한곳에 모았습니다.** Python 3.10+, Node.js 20+, WebGL을 지원하는 Chrome/Edge가 필요합니다. 추가 패키지 설치는 없습니다.

```sh
python tools/build.py
node tools/review-server.cjs
```

**[환경과 노이즈 검토실 열기](http://127.0.0.1:18769/)** → 환경 선택 → 생성기·시드·시작점 선택 → **실제 관측 생성**.

기본은 **10초, 1초 간격의 11프레임**입니다. 더 촘촘하게 보려면 0.5·0.2·0.1초 간격을, 빠르게 점검하려면 ‘한 순간’을 고르세요. 비·눈은 계산에 수 분이 걸릴 수 있습니다. 완료한 프레임부터 넘겨볼 수 있고 중지해도 이미 만든 파일은 남습니다.

**센서 종류 · 개체별 빔 각도**를 펼치면 공개 **OS1-32 U(32×512) / G(32×1,024) / OS1-128**을 고를 수 있습니다. 웹 기본은 U형이며, ‘다른 기기’로 채널별 고정 각도를 바꿉니다. 같은 기기 번호는 장면·시간·날씨를 바꿔도 유지됩니다. 추가 변동은 **각 축 ±0.01°, 평균 0°, 표준편차 약 0.00577°**의 검증용 균등분포입니다. 실제 제품 간 편차를 측정한 분포는 아니며, U/G는 서로 다른 빔 배치입니다. [범위의 근거와 사용법](docs/beam-variation-v25.md).

**반사도는 기본 켜짐**이며 체크로 끌 수 있습니다. 미교정 추정값이고 햇빛 채널은 미지원입니다.

녹색 선은 시뮬레이터의 센서 경로, 흰 화살표는 현재 센서, 금색 표식은 먼지 발생원입니다. ‘발생원 확대’로 먼지 위치를 찾을 수 있습니다. **운동 표본은 센서 관측과 별개**이며 가려짐·약한 신호 때문에 검출 노이즈가 0개일 수도 있습니다.

‘설정 저장’으로 조건을 다시 불러오고, ‘현재 프레임 저장’으로 **화면에 표시한 실제 관측 파일**을 받을 수 있습니다. 결과는 `outputs/review-demo/`에 보관하며 자동 삭제하지 않습니다. [사용법과 파일 계약](docs/review-demo.md).

## 기존 상세 시뮬레이터 실행

Python **3.10 이상**과 WebGL을 지원하는 최신 Chrome 또는 Edge가 필요합니다. 실행에 인터넷 연결, 계정, 추가 Python 패키지 설치가 필요하지 않습니다.

저장소를 내려받은 폴더에서:

```sh
python tools/serve.py
```

**[시뮬레이터 열기](http://127.0.0.1:8768/)** → 종류와 장소 선택 → **새 시드로 생성** → **10초 재생**. 시간 막대로 원하는 순간을 바로 볼 수도 있습니다.

Windows에서 `python`을 찾지 못하면 `py -3 tools/serve.py`를 사용하세요. 이미 다른 시뮬레이터가 실행 중이면 `python tools/serve.py --port 18768`을 실행하고 [18768 포트](http://127.0.0.1:18768/)를 여세요. 종료는 실행 창에서 **Ctrl+C**입니다. HTML 파일을 더블클릭하는 대신 위 방식으로 여세요.

## 화면 읽는 법

**3D 시뮬레이션**은 조작 화면입니다. 입자 운동과 지면 설정은 펼쳐서 조절할 수 있습니다. 마우스 드래그로 회전하고 휠로 확대합니다.

**확정 내용·생성 한계**에는 합의한 설정과 아직 구현·검증하지 못한 내용이 있습니다. **생성 원리·특징**에서는 계산 가정을, **소스 목록**에서는 자료의 출처와 라벨 상태를 확인합니다.

| 보기 | 의미 |
| --- | --- |
| 공간 속 입자 | 바람·낙하 운동을 보여주는 표본. 센서 관측점과 다릅니다. |
| 라이다 관측점 | 빔, 가림, 감쇠, 검출 가정을 통과한 반환점입니다. |
| 실측 비교 | 먼지·눈·비는 다른 장소의 참고 실측입니다. 동일 장면의 정답 쌍이 아닙니다. |
| 효과 전후 | 거리 오차·안개·햇빛·경계 혼합은 같은 합성 장소를 비교합니다. |

## 무엇이 매번 바뀌나요?

**같은 장소·시드·시간·설정이면 같은 결과를 재현**합니다. 시점을 돌리거나 탭을 옮기는 동작은 난수를 바꾸지 않습니다.

- **시작점·경로:** 기본은 빈 공간에서 연속 좌표를 뽑습니다. 10초 동안 XYZ와 yaw·pitch·roll을 모두 바꾸며 움직입니다. 기존 40곳 중 선택도 가능합니다.
- **충돌:** 반경 0.3m의 센서 몸체를 감싸는 보수적 상자로 전체 이동 구간과 물체·지면의 충돌을 검사합니다. 실내 높이 0.8~2.2m, 야외 0.8~6m, pitch·roll ±25° 범위입니다. 자유 비행 검토 가정이며 실제 차량 궤적은 아닙니다.
- **물체:** 새 시드가 장소에 맞는 소품의 종류·수·위치·방향·크기·반사율을 바꿉니다. 건물과 기존 기본 배치는 유지됩니다. 시퀀스 중 소품·차량·사람 자체는 움직이지 않습니다.
- **먼지:** 시퀀스마다 연결된 빈 지면에서 발생원을 뽑습니다. 한 시퀀스 안에서는 같은 세계 위치에서 방출하고 입자가 이동합니다. 멀거나 가려져 반환이 0개일 수 있습니다.
- **비·눈·안개:** 현재 빔이 볼 수 있는 공간에서 관측합니다. 입자·농도장은 세계 좌표에서 이동하며 센서에 붙어 다니지 않습니다. 강도는 기본 노브값 고정, 선택적으로 시드별 표준편차 5% 변동입니다.
- **햇빛:** 세계 태양 방향과 가림에 따른 가짜 반환 가정입니다. 공간에 균등하게 뿌리는 입자 모델이 아니며 실측 발생률은 미교정입니다.

충돌을 피하도록 후보를 거절하므로 최종 시작점·물체 위치가 정확한 공간 균등분포는 아닙니다. **같은 24개 기본 장소를 반복 생성해도 독립 장소 수가 늘지는 않습니다.**

[첨부 문제 보고서의 수정·보류 내역](docs/review-v22.md)에서 모든 항목의 상태를 확인할 수 있습니다. **정상 정지 실측·대상 센서 metadata가 필요한 교정은 아직 미완료**입니다. 비·눈의 연속 입자 계산은 무겁습니다. 이번 PC의 CLI 4개 계산 스레드에서 128채널 기준 평균 비 25.2초, 눈 17.7초/프레임이었습니다. 장면·설정·PC에 따라 달라지며 [측정 조건과 기록](docs/validation.md)을 확인하세요. 화면에 진행률을 표시하고 종류를 바꾸면 기존 계산을 취소합니다.

거리 오차 기본값은 **표준편차 0.06m**입니다. 지면 굴곡은 **높이 표준편차 0~0.5cm**, 앞뒤·좌우 기울기는 각각 **±0.6°**, 축 흔들림 진폭은 **0~0.7도 범위**입니다. 모두 사용자와 정한 검토 범위이며 장비의 실측 허용오차가 아닙니다.

## AI 에이전트에게 맡기기

에이전트에게 이 저장소를 열고 **[AGENTS.md](AGENTS.md)를 먼저 읽으라**고 알려주세요. 실행·수정 위치, 보호할 조건, 검증 명령과 데이터 계약이 정리되어 있습니다.

화면 없이 한 프레임을 계산하려면 Node.js **20 이상**도 필요합니다:

```sh
python tools/build.py
node tools/simulate.cjs --config examples/dust.json --out outputs/dust.json
```

결과에는 좌표, 검토 라벨, 빔 번호, 적용한 설정과 시드, **상대 신호·미교정 반사도 추정값**이 함께 저장됩니다. 재질 반사도는 별도의 참고 배열에 보관합니다. **Ouster의 교정 반사도는 아니며, 햇빛 모드의 신호·반사도는 아직 미구현(null)입니다.** 이미 있는 출력 파일은 덮어쓰지 않습니다. 자세한 사용법은 [에이전트 실행 안내](docs/agent-guide.md)에 있습니다.

## 10초 시퀀스 저장

```sh
node tools/sequence.cjs --kind dust --scene construction_v1 --seed 73031 --out outputs/dust-sequence-001
```

**10Hz, 0~10초의 101프레임**과 센서 위치·방향·시각·발생원 정보를 저장합니다. 기본 파일은 숫자를 그대로 저장하는 압축 바이너리(LSF1)입니다. JSON이 필요하면 `--format json.gz`를 지정하세요. 계산은 실시간보다 느리며, 화면도 계산이 끝난 다음 프레임으로 넘어갑니다. 새 시드를 주면 시작점·경로·먼지 발생원이 바뀝니다. 같은 시퀀스의 일부 프레임을 학습/테스트로 쪼개지 마세요.

이동은 네 구간을 부드럽게 출발·정지하는 6DoF 경로입니다. **프레임 내부의 회전 시간차와 외부 모터 36RPM은 아직 반영하지 않습니다.**

## 보관 범위

v24 검토실·랜덤 배치·6DoF 경로와 v22 관측 모델의 활성 소스, 장면 데이터, 실측 변환 예시, 라이브러리와 출처를 포함합니다. 별도 PC 경로 없이 실행되며, 빌드 결과는 `dist/`에 만들어집니다.

원본 PCAP, 대용량 학습 데이터, 모델 가중치, 보류한 테스트 캡처와 다른 에이전트의 진행 중인 PCD·궤적 프로젝트는 포함하지 않습니다. 사내 크레인 형상과 서로 다른 이용 조건의 실측 자료가 있으므로 **저장소 전체에 공개 재배포 허가가 부여된 것은 아닙니다.** [자료·라이선스 안내](docs/data-and-rights.md)를 확인하세요.
