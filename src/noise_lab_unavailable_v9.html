생성 보류·검증 한계

물보라·원인 미상 라벨·반사·간섭은 3D 선택에서 제외했습니다. 햇빛·안개의 새 후보는 위에서 생성할 수 있으며, 아래에는 이전 실패 이유와 현재 검증 한계를 남겼습니다.

햇빛 · 생성 후보 구현, 센서별 교정은 미완료

왜 점이 거의 없었나

이전 기본값은 ‘논문 참고 · 햇빛 합성점 0’이었습니다. 오른쪽에 장소만 보여 주었고, 햇빛 오류를 재현한 결과가 아니었습니다. ‘대상 라벨만’을 켜면 볼 대상도 없었습니다.

이전 가상 수광기 실험

태양 방향·표면·그늘 → 받는 배경광 → 가정한 광자 수 → 검출 문턱을 계산했습니다. 적응 문턱이 가짜 검출을 억제하므로 점이 적을 수 있습니다. 광학·회로 계수가 실측에 맞춰지지 않은 가상 수광기입니다.

현재 3D에서 하는 것

태양 방향의 오류 확률과 전 거리 가짜 반환을 통계적으로 생성합니다. 각도 폭·발생률은 조절 가정입니다. Ouster 햇빛 오류율을 재현한 결과는 아닙니다. 직접 포화·플레어·반사광은 여전히 미구현입니다.

실측 근거: 2022년 FZD 연구의 해당 시험에서는 OS1-32에 햇빛 유발 가짜 검출이 관찰되지 않았고, 다른 두 센서는 태양 방향의 가짜 검출을 보였습니다. 모든 Ouster 모델·조건에서 오류가 없다는 뜻은 아닙니다. 제공된 크레인 PCAP에는 배경광 채널이 있지만, 햇빛 원인 라벨과 정상 대조 캡처는 없어 발생률 교정에 바로 쓸 수 없습니다.

재검토에 필요한 것: 사용할 센서·펌웨어의 직사광/반사광 원본, 태양 방향·밝기, 정상 기준 장면, 반환 신호와 배경광 정보.

실측 논문 · Sunlight 절 · 공식 데이터 안내

이전 안개 최고점 방식 · 실패 기록

공사현장 예시에서 산란점 92,597개 중 98.3%가 폭 1m의 거리 구간에 몰렸습니다. 실제 센서의 안개 억제·검출 응답이 없어 이 껍질을 학습시킬 위험이 있습니다.

위 3D는 새 확률적 반환 후보입니다. 광자 도착 신호에 따라 거리를 추출합니다. 특정 껍질에 반복 배치하지 않지만, 실제 센서의 strongest-return 신호처리를 구현한 것은 아니므로 검증 전입니다. 이전 실패 코드는 보존했습니다.

원인 불명 Class 7 · 합성 보류

제공자의 분류 이름만으로 발생 원인을 알 수 없습니다. 실제 지형·물체의 오분류가 섞였는지 검증하지 못해 모양을 복제하지 않습니다.

위의 ‘경계 혼합·약한 신호’는 이 라벨을 재현한 것이 아닙니다. 기존 항공 실측 검토에서 원본 라벨을 볼 수 있습니다.

물보라 · 생성 보류

물보라 실측의 라벨 대응과 입도·발생량·신호 특성을 교정하지 못했습니다. 비 모델이나 임의 점군을 물보라 정답으로 바꾸지 않습니다.

유리·거울 · 정책 보류, 관측 보존

재질 표면과 반사 허상의 제거 정책을 정하지 않았습니다. 강한 반사나 투과 관측을 통째로 노이즈로 분류하지 않습니다.

임의 XYZ 점 · 현실 노이즈 학습에서 제외

위치·밀도·빈도의 근거가 없습니다. 고립점만 지우는 편향을 배우거나, 정상 표면과 구분할 수 없는 위치에 삭제 라벨을 만들 수 있습니다.

라이다 간섭·포화·번짐 · 미구현

상대 송신 타이밍과 방향, 실제 수광기의 억제·포화 응답이 필요합니다. 넓게 뿌린 점으로 대체하지 않습니다.

‘시뮬레이션 가능’은 계산과 화면 표시가 가능하다는 뜻입니다. 현재 어떤 후보도 실측 재현 또는 학습 사용을 승인한 상태는 아닙니다.
