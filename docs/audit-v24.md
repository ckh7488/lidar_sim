# v24 코드·실행 감사

기존 설명을 근거로 완료 판정을 하지 않고, 빌드에 들어가는 소스·실제 worker·저장 배열·브라우저를 확인했습니다. v23에는 고정 소품, 고정 높이의 지상 경로, 기본 라벨 표시가 남아 있어 아래를 수정했습니다.

## 현재 동작

| 항목 | 코드와 실제 출력에서 확인하는 내용 |
| --- | --- |
| 장소·물체 | 24개 기본 구조 위에 장소별 허용 소품을 실제 삼각형 메시로 추가합니다. 시드별로 종류·수·위치·yaw·scale·반사율이 달라지며 광선 교차, 날씨 가림, 경로 충돌과 뷰어에 같은 배치를 사용합니다. 건물 전체를 무한 생성하지 않습니다. |
| 시작점·경로 | 기본 `pose:random`은 연속 좌표입니다. 10초 동안 XYZ·yaw·pitch·roll이 변하며 기존 40곳 선택도 유지합니다. 센서 몸체 반경 0.3m를 포함한 전체 이동 구간을 삼각형과 검사합니다. |
| 반사도 | 검토실·상세 시뮬레이터 모두 기본 켜짐과 on/off가 있습니다. 표시 전환은 저장 XYZ·라벨을 바꾸지 않습니다. 미교정 proxy이며 햇빛 모드는 전체 미지원입니다. |
| 노이즈 | 먼지는 연결된 빈 지면의 국소 발생원, 비·눈은 세계 입자, 안개는 이동하는 농도장입니다. 센서 중심의 고정 구체를 뿌리는 기본 경로가 아닙니다. 햇빛은 세계 태양 방향·가림을 사용하는 통계 가정입니다. |

랜덤 후보 높이는 실내 0.8~2.2m, 야외 0.8~6m이며 pitch·roll은 ±25°입니다. 경유점 사이의 Z는 세계 좌표에서 직선 보간하므로 실제 지면 위 높이는 지형에 따라 조금 달라집니다. 네 이동 구간에 5차 easing을 적용하며 최고 이동속도 3m/s 미만, yaw 90°/s 이하, pitch·roll 40°/s 이하입니다. 설치 오차 ±0.6°와 몸체 운동 자세는 별도 항입니다.

충돌 검사는 센서 몸체 구를 감싼 보수적 AABB를 사용합니다. 빈 공간 후보를 거절하므로 최종 배치·시작점이 정확한 체적 균등분포는 아닙니다. 제공된 메시의 표면에 대한 검사이며 실제 차량/드론 동역학이나 완전한 다층 길찾기는 아닙니다.

## 구현 근거

- [scene_v24](../src/noise_lab_scene_v24.js): 소품 정규화, 장소별 허용 목록, 빈 공간 배치, 동일 메시 합성. 배치 키는 실제 높이/변환까지 포함합니다.
- [freepose_v24](../src/noise_lab_freepose_v24.js): 연속 시작점, 여섯 축 경로, 세계 고정 먼지 발생원.
- [geometry_v3](../src/noise_lab_geometry_v3.js): 몸체 회전 → 설치 오차 → 축 흔들림, 실제 광선 재계산과 몸체 충돌.
- [geometry worker](../src/noise_lab_geometry_worker_v3.js), [weather worker](../src/noise_lab_motion_worker_v6.js): 동일한 sceneLayout을 교차·가림 계산에 전달합니다.
- [review viewer](../src/review_demo_viewer.js): 같은 물체 모델·변환과 원래 LSF 배열을 표시하며 XYZ+라벨 SHA-256을 검증합니다. 몸체 앞/Y/Z 축과 자세 수치를 표시합니다.

LSF 메타데이터는 schema 6입니다. sceneLayout·sensorPose·sequencePlan·routePreview는 재현/검토 정보이며 센서 학습 특징이 아닙니다. 기존 지상 모드는 명시적인 `scenario:legacy-v23`로 검사합니다. 신규 기본값의 테스트를 옛 모드로 돌려 통과시키지 않았습니다.

## 발견하고 고친 화면 문제

조건을 바꾸면 이전 랜덤 소품·관측·경로를 지웁니다. 이는 메모리의 표시 객체 해제이며 디스크 파일을 삭제하지 않습니다. 계산 중 첫 프레임을 표시한 뒤 전체 프레임 수가 1/1로 남던 갱신 오류도 수정했습니다. 반사도 범례, 실제 몸체 pitch·roll과 소품 수를 표시합니다. 책상 의자 방향도 정리했습니다.

## 검증

최종 집계는 [validation-v24.json](validation-v24.json)에 보관합니다. 아래 검사는 모두 실제 코드로 실행하며 문서의 기대값만 읽는 검사가 아닙니다.

- `audit-geometry-v24.cjs`: 24개 환경 × 두 소품 시드 × 41개 시작 조건, 1,968개 경로와 198,768개 자세. 별도 BVH의 최근접 거리·구간 삼각형 교차로 검증합니다.
- `audit-geometry-v24.cjs --random-grid`: 각 환경 40개 시드, 0/4294967295 포함. 실제 기본 선택과 같은 연속 시작점·배치 결합을 검사합니다. 같은 테스트의 `--cases`로 장면 묶음을 나누어 실행할 수 있습니다.
- `audit-runtime-v24.cjs`: 실내 15×6 + 야외 9×8 = 162개 지원 조합, 프레임당 131,072빔. 경로 끝점·재현 검사를 포함해 234스캔. 가구 방향 수정 뒤 영향받은 6환경 36조합/54스캔도 다시 실행했습니다.
- `boundaries-v24.cjs`: 모든 24환경의 uint32 양 끝 시드 48스캔, 거리오차 0/0.15m·안개 가시거리 50/2,000m·해가 진 햇빛·최대 비/눈·풍속의 경계 사례.
- `sensor-poses.cjs`: 기존 960개 시작점, 지형 끝값, 각 위치 2,048빔 축소 관측과 독립 Three.js Euler 계산으로 yaw·pitch·roll·광학 원점 회전을 검증합니다.
- `review-demo.cjs`: 전 환경 API 생성, 8종 생성기, LSF/브라우저 디코더/직접 runtime 일치, 취소, 재현, 소품 끄기, 입력 거절, 11프레임 재생 데이터.
- `sequence-export.cjs`: 실제 10Hz 101프레임, 고유 좌표 해시 101개, JSON 압축 왕복, 기존 파일 덮어쓰기 거절.
- 기존 worker 생명주기·채널·강수 시간 일관성·센서 metadata·공통 관측·지상 호환·합성 교정 검사를 유지했습니다.

처음 소품 광선 검사는 경계 상자 중심을 쏘아 책상과 호퍼의 빈 공간을 통과한 일부 사례를 실패로 표시했습니다. 실제 삼각형 표면 방향을 쏘는 검사로 바로잡고 다시 실행했습니다. 실패를 회피하기 위해 소품이나 광선 계산을 끄지 않았습니다.

브라우저에서는 상세 시뮬레이터의 24장면 연속 전환, 날씨 9회 전환, 모든 설명 탭 왕복, 0~10초 이동, 반사도 전환을 확인했습니다. 검토실은 24미리보기, 실제 생성, 재생 끝점, 시드 변경 후 초기화, 반사도 전환 후 좌표 해시 유지, 실제 자세/소품 표시를 확인했습니다. 관측된 애플리케이션 오류는 없었고 동봉 Three.js 구형 배포 형식 경고는 남습니다.

## 이 검사로 보장하지 않는 것

모든 uint32 시드와 연속 파라미터 조합을 소진한 것은 아닙니다. 코드·기하·실행의 유한 검사이며 현장 노이즈 충실도나 학습 성능 보장이 아닙니다. `field_calibrated=false`, `training_approved=false`를 유지합니다.

- 기본 건물 구조와 기존 물체는 유지되며, 추가 소품도 한 시퀀스 안에서는 정지합니다. 사람·차량 자체 이동과 수십 m 높이의 크레인 설치 분포는 미구현입니다.
- 먼지 발생원이 멀거나 가려지면 반환 0개가 정상입니다. 비·눈·안개의 후보가 전 관측 거리에서 가능해도 최종 검출 밀도가 균등하지 않습니다.
- 반사도는 Ouster 교정값이 아닙니다. 햇빛의 전체 신호/반사도는 NaN, JSON에서는 null이며 임의 값으로 채우지 않습니다.
- 강수 지붕 가림은 0.5m 격자 근사입니다. 평균 감쇠는 광로에 대한 단순 모델이며 정밀한 차폐 유동·젖음·튀김·적설을 재현하지 않습니다.
- 외부 모터 36RPM, 빔별 시각과 스캔 내부 운동 왜곡, 유리·거울 허상, 수광 회로의 실제 간섭/포화는 미구현입니다.
