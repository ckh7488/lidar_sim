# 모델의 한계

이 문서는 **구현 여부**와 **현장 타당성**을 구분합니다. 실행 테스트 통과는 센서에 맞는 분포나 학습 효과를 입증하지 않습니다.

## 생성하는 후보

- 먼지: 국소 발생, 바람, 침강, 절차적 상승류/회오리, 표면 접촉을 근사합니다. 유체역학 CFD, 장비 주변 실제 유동, 재비산과 굵은 먼지는 미구현입니다. 원본 먼지 패치를 랜덤 복사하지 않습니다.
- 비·눈: 0.5~100m 첫 표면 앞의 빔 부피에서 입자 교차를 추출합니다. 가림·감쇠·검출 때문에 가까운 반환이 더 많을 수 있습니다. 전 거리 가능성은 전 거리 동일 개수를 뜻하지 않습니다. 작은 빗방울의 개별 반환, 눈 결정의 실제 형상, 젖은 표면과 적설은 생략했습니다.
- 안개: 감쇠와 확률적 산란 반환을 근사합니다. 가시거리 500m, 산란 민감도 10^-3.3의 약한 기본값은 시각 검토 가정입니다. 농도장이 바람에 따라 이동하지만 실제 유체 수송 방정식은 풀지 않습니다. 과거 argmax 기반 조밀한 껍질 모델은 학습에서 제외했습니다.
- 햇빛: 태양 방향의 가짜 반환 확률과 0.3~100m 가짜 거리를 추출하는 통계 후보입니다. 기본 최대 확률 0.05, 각도 폭 2°는 조절 가정입니다. 실제 Ouster 오류율로 적합한 값이 아닙니다. 고장 상태 크레인 PCAP의 밝은 NIR·빈 범위·고립점은 햇빛 정답 라벨이 아닙니다.
- 거리 오차: 실제 표면을 빔 방향으로 흔듭니다. 표면 라벨을 유지합니다. 기본 정규 오차 σ=0.06m는 사용자가 시각 검토한 값입니다.
- 경계 혼합·약한 신호: 반환 위치 변화와 누락을 근사합니다. 달라진 경계 표면에 붙는 라벨 2와 약한 표면을 통째로 삭제 정답으로 삼지 않습니다.

## 보류하거나 포함하지 않은 것

거울·유리는 사용자의 제거 정책이 정해질 때까지 보존합니다. 원인 불명의 항공 Class 7을 특정 노이즈 분포로 복제하지 않습니다. 원본 라벨 품질이 검증되지 않은 분무 전체를 제거 라벨로 쓰지 않습니다.

직사광 포화, 광학 플레어, 센서 고유 전자회로, 다중 에코, 완전한 수신 파형은 재현하지 않습니다. 모든 스캔을 같은 순간으로 계산하므로 회전 중 물체·센서 이동과 외부 모터 36RPM의 시각별 자세는 별도 구현이 필요합니다.

## 무작위화의 범위

형상/강도 분포의 숫자는 `configs/parameter_distributions_v18.json`에 있습니다. 원형 위상은 일반 평균·표준편차로 요약하지 않으며, 고정 노브는 std=0으로 기록합니다. 기하 추출은 소수 셋째 자리로 반올림되므로 등록한 연속 균등분포와 아주 작은 양자화 차이가 있습니다.

비·눈·안개 강도 변동을 켜면 노브값이 평균이고, 균등분포의 표준편차가 평균의 5%입니다. 경계 근처에서는 UI 허용 범위로 제한되어 최종 평균/표준편차가 달라질 수 있습니다. 실제 sampled value와 clipped를 보관하세요.

24개 기본 구조는 고정이며 소품만 시드별로 추가 배치합니다. 무한 랜덤 건물 지도를 제공하지 않습니다. 실측과 합성의 센서/장소/조건은 일치하지 않습니다. 같은 시드의 반복성과 다양한 시드는 일반화 성능 검증을 대신하지 않습니다.


## 센서 위치 카탈로그 (v19)

24개 장면에 40곳씩 제공합니다. 물체 충돌과 연결된 바닥을 검사한 지상 설치 샘플이며, 정확한 체적 균등 표본이나 현실의 작업자 이동 확률은 아닙니다. 높이 1.2~2.1m와 yaw 0~360°는 새 설치 가정입니다. 지면/기울기/거리 오차의 기존 확정값과 별개입니다. 고소 크레인 설치, 계단·다층 이동, 스캔 중 운동 왜곡을 포함하지 않습니다. 기존 카탈로그의 설치 가정입니다. v24 기본은 빈 공간 연속 시작점과 6DoF 경로이며 높이 실내 0.8~2.2m/야외 0.8~6m, pitch·roll ±25°, 센서 몸체 반경 0.3m입니다. 수십 m 크레인 상부 설치·다층 이동·차량 동역학은 지원하지 않습니다.

960개 관측 위치는 960개 독립 환경을 뜻하지 않습니다. 특히 같은 장소의 v1~v3에도 형상 자산이 공유됩니다. 일반화 평가는 장면 family/원본을 먼저 분리한 뒤 시점·날씨 시드를 배정해야 합니다. 검증용 출력 시퀀스는 학습·검증·시험 데이터 분할이 아니며 학습을 실행하지 않았습니다.


## 반사도 채널 (v20)

재질 가정값은 내부 rho/albedo에서 가져온 referenceScan으로만 보관합니다. 실제 센서 입력과 분리해야 합니다. 반환점의 reflectivityProxy는 상대 신호에 관측거리²를 곱한 미교정 값이며 입사각·대기 감쇠·센서 감도를 보정하지 않습니다. 안개의 파형 적분 신호는 다른 모드와 척도가 같지 않습니다. 시드별 재질 무작위화, 측정 신호의 센서별 양자화와 교정은 구현하지 않았습니다.

햇빛의 신호·반사도는 전체 null입니다. 기존 0/1 powers는 라벨 표식이므로 폐기한 의미이며, 정상점과 노이즈의 세기를 재현하지 못합니다. 현재 위치 생성 모형만으로 현실적인 햇빛 반사도를 억지로 채우면 잘못된 학습 단서를 만듭니다. 이 한계는 확정 탭에도 표시합니다.


## 시퀀스와 발생원 (v21)

- 경로는 세 개의 충돌 없는 직선 구간입니다. 5차 보간으로 경유점에서 속도·가속도가 0이 되어 끊김 없이 출발/정지합니다. 각 구간 후보는 1~2.5m, 좁으면 0.35~1m로 줄입니다. 시간 배분은 `2 + 4 × 구간길이 / 전체길이`초이며 합계 10초입니다. yaw 변화는 최대 30°/s입니다. 장비/작업자의 실측 동작 분포에서 학습한 경로는 아닙니다.
- 충돌 검사는 반경 0.35m, 지면 위 0.08~2.4m의 보수적인 상자로 합니다. 도로 주행 규칙, 계단, 사람 회피, 차량 운동학은 포함하지 않습니다. 모든 임의 시드의 경로 성공을 수학적으로 보장하지 않으며 찾지 못하면 오류를 표시합니다.
- 먼지 발생원은 장면 바닥 영역의 XY 균등 후보를 뽑아 물체 내부·장면 밖·시작 센서에서 0.75m 미만 또는 95m 초과를 거부합니다. 좁은 장면에서 512회 실패하면 첫 안전 경로 위를 사용하고 `fallbackToRoute:true`를 기록합니다. 최종 분포는 잘린 자유 공간 분포이며 전 체적 균등이나 현장 먼지 발생 통계가 아닙니다. 가려져 센서 반환이 0일 수 있습니다.
- 발생원은 시퀀스 안에서 정지해 있습니다. 방출된 먼지는 계속 움직이며 10초 동안 7,500개 질량 묶음을 시간에 따라 투입합니다. 움직이는 차량의 먼지 발생원, 재비산, 시뮬레이션 시작 전 먼지는 구현하지 않았습니다. 0초에 아직 방출된 먼지가 없는 것은 정상입니다.
- 지형·설치 오차·날씨 세기는 시퀀스 단위로 유지하고 측정 난수는 시각별로 분리합니다. 비·눈의 물리 입자는 세계 좌표와 ID를 유지하며, 실제 빔 교차 후보에서 광자 검출을 합니다. 표시에는 후보 일부만 사용합니다. 안개는 이동하는 농도장과 시간별 확률적 검출이며 CFD는 아닙니다.
- 매 프레임은 순간 스캔입니다. 10Hz 프레임을 만들었다고 빔별 시각·deskew·외부 36RPM 회전이 구현된 것은 아닙니다. 화면 재생은 계산 완료를 기다려 진행하며 실제 10초보다 오래 걸릴 수 있습니다.
