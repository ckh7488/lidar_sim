# 모델의 한계

이 문서는 **구현 여부**와 **현장 타당성**을 구분합니다. 실행 테스트 통과는 센서에 맞는 분포나 학습 효과를 입증하지 않습니다.

## 생성하는 후보

- 먼지: 국소 발생, 바람, 침강, 절차적 상승류/회오리, 표면 접촉을 근사합니다. 유체역학 CFD, 장비 주변 실제 유동, 재비산과 굵은 먼지는 미구현입니다. 원본 먼지 패치를 랜덤 복사하지 않습니다.
- 비·눈: 0.5~100m 첫 표면 앞의 빔 부피에서 입자 교차를 추출합니다. 가림·감쇠·검출 때문에 가까운 반환이 더 많을 수 있습니다. 전 거리 가능성은 전 거리 동일 개수를 뜻하지 않습니다. 작은 빗방울의 개별 반환, 눈 결정의 실제 형상, 젖은 표면과 적설은 생략했습니다.
- 안개: 감쇠와 확률적 산란 반환을 근사합니다. 가시거리 500m, 산란 민감도 10^-3.3의 약한 기본값은 시각 검토 가정입니다. 포그 필드의 시간 이동은 없습니다. 과거 argmax 기반 조밀한 껍질 모델은 학습에서 제외했습니다.
- 햇빛: 태양 방향의 가짜 반환 확률과 0.3~100m 가짜 거리를 추출하는 통계 후보입니다. 기본 최대 확률 0.05, 각도 폭 2°는 조절 가정입니다. 실제 Ouster 오류율로 적합한 값이 아닙니다. 고장 상태 크레인 PCAP의 밝은 NIR·빈 범위·고립점은 햇빛 정답 라벨이 아닙니다.
- 거리 오차: 실제 표면을 빔 방향으로 흔듭니다. 표면 라벨을 유지합니다. 기본 정규 오차 σ=0.06m는 사용자가 시각 검토한 값입니다.
- 경계 혼합·약한 신호: 반환 위치 변화와 누락을 근사합니다. 달라진 경계 표면에 붙는 라벨 2와 약한 표면을 통째로 삭제 정답으로 삼지 않습니다.

## 보류하거나 포함하지 않은 것

거울·유리는 사용자의 제거 정책이 정해질 때까지 보존합니다. 원인 불명의 항공 Class 7을 특정 노이즈 분포로 복제하지 않습니다. 원본 라벨 품질이 검증되지 않은 분무 전체를 제거 라벨로 쓰지 않습니다.

직사광 포화, 광학 플레어, 센서 고유 전자회로, 다중 에코, 완전한 수신 파형은 재현하지 않습니다. 모든 스캔을 같은 순간으로 계산하므로 회전 중 물체·센서 이동과 외부 모터 36RPM의 시각별 자세는 별도 구현이 필요합니다.

## 무작위화의 범위

형상/강도 분포의 숫자는 `configs/parameter_distributions_v18.json`에 있습니다. 원형 위상은 일반 평균·표준편차로 요약하지 않으며, 고정 노브는 std=0으로 기록합니다. 기하 추출은 소수 셋째 자리로 반올림되므로 등록한 연속 균등분포와 아주 작은 양자화 차이가 있습니다.

비·눈·안개 강도 변동을 켜면 노브값이 평균이고, 균등분포의 표준편차가 평균의 5%입니다. 경계 근처에서는 UI 허용 범위로 제한되어 최종 평균/표준편차가 달라질 수 있습니다. 실제 sampled value와 clipped를 보관하세요.

장소별 예시는 고정 배치이며 무한 랜덤 지도를 제공하지 않습니다. 실측과 합성의 센서/장소/조건은 일치하지 않습니다. 같은 시드의 반복성과 다양한 시드는 일반화 성능 검증을 대신하지 않습니다.
