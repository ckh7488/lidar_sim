# 자료, 출처와 이용 범위

이 저장소는 사용자가 지정한 **사내 Git 인계본**입니다. 저장소 전체에 MIT/CC0 같은 단일 공개 라이선스를 선언하지 않습니다.

## 포함 자료

- DEMO 메시 24개, 공개 OS1 기준 빔 배열, 기존 비교 프로필, 현재 에셋 미리보기.
- 이미 열람한 실측 변환 36예시: UCHILE-Dust, Ouster 먼지 자료, MSU-4S, MirrorSentinel 변환본, SemanticSpray++ 변환본, 항공 Class 7 참고 자료.
- 이전 크레인·먼지·항공 분석과 이미 변환한 표시 자료. 원본 PCAP 및 보류한 테스트 캡처는 포함하지 않습니다.
- `provenance/source_snapshot.json`: 가져온 원본 상대 경로, 인계 파일, 바이트 수, SHA-256. 일부 코드/경로는 인계 과정에서 조정했으므로 이는 **가져오기 시점**의 기록입니다. 현재 빌드 입력 해시는 `dist/build-manifest.json`입니다.

데이터별 출처, 접근 상태, 라벨 한계와 이용 조건은 `data/noise_lab_v1/index.json`의 `registry`, `real[].source_url`, `real[].label_status`를 확인하세요. 화면의 **소스 목록**도 같은 registry를 읽습니다. 이미 가공된 작은 예시의 보관은 원본 데이터 전체의 이용 허가를 의미하지 않습니다.

## 형상과 라이브러리

Kenney의 해당 공개 팩은 CC0입니다. 팩별 라이선스는 `licenses/kenney/`, 출처와 다운로드 해시는 `provenance/kenney_manifest*.json`에 있습니다. 원본 GLB 전체는 넣지 않았으며 실행에 필요한 변환 메시를 포함했습니다.

NOCOL에서 사용자가 제공한 크레인 형상은 사내 자료로 취급합니다. 공개 팩과 같은 라이선스로 재분류하지 않습니다. 공개 배포 전에는 형상·실측 데이터·보고서 각각의 권리를 검토해야 합니다.

Three.js 0.160.1과 three-mesh-bvh 0.7.6의 고지문은 `vendor/`에 보존했습니다. 웹 실행은 CDN을 호출하지 않습니다. 사용자가 출처 링크를 누르면 외부 페이지로 이동합니다.

## 라벨 해석

제공자 라벨, 변환본에서 추정한 색상 대응, 원인 미확인 이상점은 서로 다릅니다. 원본 라벨을 수정해 생성 모델을 정당화하지 않습니다. 항공 Class 7, 밝은 NIR, range=0, 고장 캡처의 빈 부분을 먼지·햇빛 정답으로 확정하지 않습니다. 시험용으로 보류한 원본 캡처를 탐색하거나 재분할하지 마세요.
