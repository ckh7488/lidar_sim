# 검증

## 재현 명령

```sh
python tools/build.py
python tools/verify.py
node tests/worker-lifecycle.cjs
node tests/simulator.cjs
```

`verify.py`는 빌드 입력 해시, 24개 장면과 36개 실측 데이터의 구조, 활성 메시 해시, 로컬 HTML 연결을 검사합니다. 외부 사이트의 접근 상태는 검사하지 않습니다.

`worker-lifecycle.cjs`는 취소, 오래된 응답, worker 재사용, 실행 오류, 메시지 오류, 타임아웃과 복구 등 10가지 동작을 검사합니다.

`simulator.cjs`는 실제 빌드의 worker를 Node에서 실행합니다. 3,000개 기하 설정, 종류별 5,000개 강도 샘플, 8개 모델 경로, 동일 시드 재현, 새 시드 변화, 표면 거리 RMS와 world-view 표면 공유를 확인합니다. 결과는 `outputs/validation.json`에 저장됩니다. fog/edge는 무거우므로 수 분이 걸릴 수 있습니다. 한 프로세스로 실행하고 완료 메시지 또는 오류를 확인하세요.

브라우저에서는 종류 변경, 장소 변경, 확정/원리 탭 왕복, 관측/운동 보기, `#sim-view[data-ready]`, 오류 로그를 확인합니다. 화면의 주황 입자를 관측점으로 세지 않습니다.

## 이번 인계 기록

2026-10-08 Windows / Python 3.12 / Node 20.18.1에서 위 네 명령이 통과했습니다. 실제 131,072개 빔으로 8개 모델 경로를 실행했습니다. 동일 시드 좌표·라벨 해시 일치, 새 시드 변화, 기본 거리 RMS 약 0.0600m, 10개 worker 검사를 확인했습니다. 브라우저에서도 모드 전환과 확정 탭 왕복을 확인했으며 콘솔 오류는 없었습니다. 세부 결과는 [validation-handoff.json](validation-handoff.json)에 보관합니다. `reference/evidence/`는 이전 작업의 기록이며 이번 패키지를 새로 실행한 검사와 구분합니다. 기존 스크린샷이나 이전 PASS 파일만으로 새 변경을 통과 처리하지 않습니다.

수치 검사는 구현의 일관성을 확인합니다. 현장 실측 교정, 센서별 검출률, 실제 제거 성능, 학습/테스트 성능은 검증 대상이 아니며 승인하지 않았습니다.

Git 서버에 올린 커밋을 빈 폴더에 다시 clone한 뒤 빌드·자산/링크 검사·worker 검사를 통과했습니다. 새 복사본의 거리 오차 프레임은 73,117점이며 좌표/라벨 SHA-256이 첫 작업본과 정확히 일치했습니다. 검사 후 추적 파일의 변경도 없었습니다. 이 기록은 코드 커밋 `1daea176`을 대상으로 하며 이후 인계 기록 수정은 문서에만 해당합니다.


## v19 센서 위치 검증 · 2026-10-09

`node tests/sensor-poses.cjs`는 **24개 장면 × 40곳 = 960곳 전부**를 검사했습니다. 지면 σ=0cm와 0.5cm의 충돌 여유, 최소 위치 간격, 동일 위치 재현, 연속 40시드의 위치 전수 선택, yaw 회전 및 잘못된 위치 거부를 통과했습니다. 960곳마다 **축소 2,048빔**을 실제 재계산했고 각 장면의 40개 거리 배열이 모두 달랐습니다. 960곳 모두를 전체 해상도로 검사했다는 뜻은 아닙니다.

`node tests/simulator.cjs`는 공사장 예시 1의 새 자동 위치(seed 73031, 위치 12/40, 시간 3.25초)에서 **131,072빔 × 8개 모델 경로**를 통과했습니다. 먼지·비·눈·안개·햇빛·거리 오차·약한 신호·경계 혼합, 동일 시드 재현, 수동 위치 유지, 비/눈 운동 표본의 센서 주변 100m 범위와 표면 공유를 확인했습니다. 별도로 이전 원점의 거리 오차 결과가 v18 해시 `8ebb172710f4b78f11e85fd7c4b7bc880e8ec01dde36e72ea1ad02e7cf6a1409`와 정확히 일치했습니다.

Python 빌드/검사(205개 입력, 24장면, 실측 36예시, 깨진 로컬 링크 0개)와 10개 worker 검사를 통과했습니다. 브라우저에서 자동 위치 변화, 수동 위치 유지, 40→1 순환, 복도 전환, 원점 비교, 확정 탭 왕복을 확인했고 콘솔 오류는 0개였습니다. 좌우 비교창 높이도 맞춰 확인했습니다. 세부 실행 기록은 [validation-sensor-v19.json](validation-sensor-v19.json)입니다.

설치 위치 다양성과 구현 일관성에 대한 검사입니다. 새 실측 교정이나 학습 성능 검증은 하지 않았습니다. 이전 인계 기록은 v18 고정 원점 기록으로 그대로 보존합니다.
