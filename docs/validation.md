# 검증

## 재현 명령

```sh
python tools/build.py
python tools/verify.py
node tests/worker-lifecycle.cjs
node tests/simulator.cjs
```

`verify.py`는 빌드 입력 해시, 24개 장면과 36개 실측 데이터의 구조, 활성 메시 해시, 로컬 HTML 연결을 검사합니다. 외부 사이트의 접근 상태는 검사하지 않습니다.

`worker-lifecycle.cjs`는 취소, 오래된 응답, worker 재사용, 실행 오류, 메시지 오류, 타임아웃과 복구 등 11가지 동작을 검사합니다. 진행률 응답이 완료로 처리되지 않는지도 확인합니다.

`simulator.cjs`는 실제 빌드의 worker를 Node에서 실행합니다. 3,000개 기하 설정, 종류별 5,000개 강도 샘플, 8개 모델 경로, 동일 시드 재현, 새 시드 변화, 표면 거리 RMS와 world-view 표면 공유를 확인합니다. 결과는 `outputs/validation.json`에 저장됩니다. fog/edge는 무거우므로 수 분이 걸릴 수 있습니다. 한 프로세스로 실행하고 완료 메시지 또는 오류를 확인하세요.

브라우저에서는 종류 변경, 장소 변경, 확정/원리 탭 왕복, 관측/운동 보기, `#sim-view[data-ready]`, 오류 로그를 확인합니다. 화면의 주황 입자를 관측점으로 세지 않습니다.
